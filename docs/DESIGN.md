# Home hub design, in short

Full version: the Claude Doc "Home hub: map and design", 28 October 2026.

- Home: rooms as cards, one switch per room, tiles for each thing, All off and three scenes at the top, the robot's status line.
- Things: every device from every brand, grouped by room; rename, rooms, hide.
- Scenes: one tap sets many things; a scene is saved from how the house is now.
- Schedules: one sentence each (what, does, when, how often), the next three runs shown in words. Tuya can hold a timer itself; the rest run on the hub device (the iPad kept open at home).
- Dustin: one status line, Clean now, Go home, Find me, particular cleans, quiet hours, parts counters, a week view, history, errors in English.
- Settings: brand keys with a Save and find things button, rooms, the hub, home for sunrise and sunset, copy setup to the other device, theme.
